# nodls_demo
Nodls `sqlcmd` command demo.

The [nodls](https://nodlsql.github.io) server combines an extended SQL query API with a [jsonb](https://docs.rs/jsonb/latest/jsonb/) data model that promotes fast iterating development and maintenance of DBMS applications.
