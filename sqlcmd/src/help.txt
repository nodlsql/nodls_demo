[help create dataset]
CREATE DATASET command help
Use CREATE DATASET to define a new dataset.

Minimal dataset create example:
CREATE DATASET myds;

Full featured example:
CREATE DATASET myds
  PRIMARY KEY(a.b, c),
  UNIQUE INDEX uix(a),
  INDEX dupix(b),
  RELATIONSHIP rs(tgtds);

[help alter dataset]
ALTER DATASET command help
Adds or drops relationships, indexes, or the primary key.

Example:
ALTER DATASET myds
  DROP RELATIONSHIP rs,
  ADD RELATIONSHIP nurs(tgtds),
  ADD PRIMARY KEY(b, c),
  DROP INDEX uix;

[help drop dataset]
DROP DATASET command help
Drops a dataset and associated indexes and relationships.

Example:
DROP DATASET myds;

[help describe dataset]
DESCRIBE DATASET command help
Displays the CREATE DATASET statement, including indexes and relationships.

Example:
DESCRIBE DATASET myds;

To list all the datasets:
SELECT name FROM DATASET;

[help select list]
SELECT FROM list help
Specifies the dataset list in the FROM clause.

Examples:
SELECT a, b FROM myds;
SELECT d.a, u.b FROM myds d, urds u WHERE d.x = u.y;

[help select predicates]
SELECT FROM WHERE predicates help
Uses WHERE clause predicates to filter the result set on path expressions
like a, a.b, a.b.c. Path expressions can be preceded by relationship navigation.

The following operators:
=, <>, >=, <=, <, >
IN, NOT IN
IS NULL, IS NOT NULL
LIKE, NOT LIKE
REGEXP, NOT REGEXP

Examples:
SELECT * FROM myds WHERE a IN (2, 3) AND b = c.d + 1;
SELECT * FROM myds WHERE a LIKE 'H. ther%';
SELECT * FROM myds WHERE a REGEXP '^H. ther.*$';

[help select projection]
SELECT projection help
Specify projection as a comma-separated list of path and relationship expressions.

Examples:
SELECT 1 + 1.50;
SELECT a.b, c FROM myds;
SELECT rs.* FROM myds;

[help insert]
INSERT INTO command help
Inserts values into a dataset.

Example:
INSERT INTO myds VALUES '{"a": 1, "b": "hi"}', '{"a": 2}';

[help update]
UPDATE SET or DELETE command help
Updates or deletes JSON elements within dataset items.

Examples:
UPDATE myds SET a = 2, b = 'hello' WHERE a = 1;
UPDATE myds DELETE c, d WHERE a = 1;

[help delete]
DELETE FROM command help
Deletes dataset items.

Example:
DELETE FROM myds WHERE a = 1;

[help relationship create]
CREATE DATASET RELATIONSHIP/ ALTER DATASET ADD RELATIONSHIP help
Creates a relationship that binds to the primary key of the target dataset.

Examples:
CREATE DATASET myds RELATIONSHIP rs(tgtds);
ALTER DATASET myds ADD RELATIONSHIP rs(tgtds);

[help relationship drop]
ALTER DROP relationship help
Drops a relationship.

Example:
ALTER DATASET myds DROP RELATIONSHIP rs;

[help relationship insert]
INSERT INTO relationship help
Adds a relationship link. Values must match existing primary key segments of the target dataset, in declaration order.

Example:
INSERT INTO myds.rs VALUES ('hi', 1) WHERE a = 2;

[help relationship delete]
DELETE FROM relationship help
Deletes relationship successors.

Example:
DELETE FROM myds.rs VALUES ('hi', 1) WHERE a = 2;

[help relationship predicate]
SELECT FROM WHERE relationship predicate help
Filters items through relationship or inverse relationship navigation. These can be followed by path or JSONPath expressions.

Examples:
SELECT * FROM myds WHERE rs.d = 1;
SELECT * FROM tgtds WHERE INVERSE(myds.rs).a = 2;

[help relationship projection]
SELECT relationship projection help
Projects dataset item content through relationship or inverse relationship navigation.

Examples:
SELECT a, b, rs.d FROM myds;
SELECT b, c.d, INVERSE(myds.rs).* FROM tgtds;

[help JSONPath]
JSONPath expressions help
You can combine JSONPath expressions with alias and relationship navigation.

Examples:
SELECT a[1,2] FROM myds;
SELECT * FROM myds WHERE a[*]?(@.b >= 2) IS NOT NULL;

Example with alias 'm' and relationship 'rs':
SELECT m.rs.$.* FROM myds m;
