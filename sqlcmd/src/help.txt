[help create dataset]
CREATE DATASET command help
Use CREATE DATASET to define a new dataset.

Minimal dataset create example:
CREATE DATASET myds;

Full featured example:
CREATE DATASET myds
  PRIMARY KEY(a.b, c)
  UNIQUE INDEX uix(a)
  INDEX dupix(b)
  RELATIONSHIP rs(tgtds);

The relationship rs allows to bind myds items to tgtds items through tgtds primary key.

[help alter dataset]
ALTER DATASET command help
Adds or drops relationships, indexes, or the primary key.

Example:
ALTER DATASET myds
  DROP RELATIONSHIP rs
  ADD RELATIONSHIP nurs(tgtds)
  ADD PRIMARY KEY(b, c)
  DROP INDEX uix;

[help drop dataset]
DROP DATASET command help
Drops a dataset and associated indexes and relationships.

Example:
DROP DATASET myds;

[help describe dataset]
DESCRIBE DATASET command help
Displays the CREATE DATASET statement, including indexes and relationships.

Example:
DESCRIBE DATASET myds;

To list all the datasets:
SELECT name FROM DATASET;

[help select list]
SELECT FROM list help
Specifies the dataset list in the FROM clause.

Examples:
SELECT a, b FROM myds;

Multiple datasets and aliases can be defined for joins.

Example:
SELECT d.a, u.b FROM myds d, urds u WHERE d.x = u.y;

[help select predicates]
SELECT FROM WHERE predicates help
WHERE clause predicates filter the result set on path expressions like a, a.b, a.b.c.
Path expressions can be preceded by relationship navigation.

The following operators are supported:
=, <>, >=, <=, <, >
IN, NOT IN
IS NULL, IS NOT NULL
LIKE, NOT LIKE
REGEXP, NOT REGEXP

Examples:
SELECT * FROM myds WHERE a IN (2, 3) AND b = c.d + 1;
SELECT * FROM myds WHERE a LIKE 'H. ther%';
SELECT * FROM myds WHERE a REGEXP '^H. ther.*$';

You can also use direct or inverse relationship navigation.
In the following example the relationship rs is traversed to filter the path expression 'd' in the target dataset.

Example:
SELECT * FROM myds WHERE rs.d = 1;

Inverse navigation example:
SELECT * FROM tgtds WHERE INVERSE(myds.rs).a = 2;

[help select projection]
SELECT projection help
The SELECT projection is a comma-separated list of path and relationship expressions.

Examples:
SELECT 1 + 1.50;
SELECT a.b, c FROM myds;
SELECT rs.* FROM myds;

[help insert]
INSERT INTO command help
Inserts dataset items into a dataset.

Example:
INSERT INTO myds VALUES
  '{"a": 1, "b": "hi"}',
  '{"a": 2}';

Relationship elements can also be added to the new items.
In the example below, ('hello', 1) maps to the primary key segments of
the rs target dataset. The nurs target dataset has only one primary key segment.

Example:
INSERT INTO myds VALUES
  '{"a": 1, "b": "hi"}' rs ('hello', 1) ('there', 2) nurs (3),
  '{"a": 2}';

[help update]
UPDATE SET, DELETE, INSERT, REMOVE command help
Updates or deletes JSON elements and relationship elements within dataset items.

Examples:
UPDATE myds
    SET a = 2 b = 'hello'
    DELETE c d
  WHERE a = 1;

The following example adds and removes relationship elements.

Example:
UPDATE myds
    INSERT rs ('hi', 1) ('there', 2) nurs (3)
    REMOVE rs ('hello', 3)
  WHERE a = 4;


[help delete]
DELETE FROM command help
Deletes dataset items.

Example:
DELETE FROM myds WHERE a = 1;

[help JSONPath]
JSONPath expressions help
You can combine JSONPath expressions with alias and relationship navigation.

Examples:
SELECT a[1,2] FROM myds;
SELECT * FROM myds WHERE a[*]?(@.b >= 2) IS NOT NULL;

Example with alias 'm' and relationship 'rs':
SELECT m.rs.$.* FROM myds m;
