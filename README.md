# nodls_demo
Nodls `sqlcmd` command demo.

The [nodls](https://nodlsql.github.io/index.html) server combines an extended SQL query API with a [jsonb](https://docs.rs/jsonb/latest/jsonb/) data model that promotes fast iterating development and maintenance of DBMS applications.

It supports [ACID](https://en.wikipedia.org/wiki/ACID) transactions and data analysis queries.
